# Ziftee apps for Android (test builds)

Install the Ziftee test apps on any Android phone. No GitHub account is needed.

| App | For | Download |
|---|---|---|
| **Ziftee** | Customers ordering food | [ziftee-customer.apk](https://github.com/deepakloomsberries/ziftee-apps/releases/latest/download/ziftee-customer.apk) |
| **Ziftee Partner** | Restaurants | [ziftee-partner.apk](https://github.com/deepakloomsberries/ziftee-apps/releases/latest/download/ziftee-partner.apk) |
| **Ziftee Rider** | Delivery partners | [ziftee-rider.apk](https://github.com/deepakloomsberries/ziftee-apps/releases/latest/download/ziftee-rider.apk) |

These links always download the newest build. Build date and number:
[latest release](https://github.com/deepakloomsberries/ziftee-apps/releases/latest).

## How to install

1. Open a download link above on your Android phone.
2. Open the downloaded file. If Android asks, allow your browser to install unknown apps.
3. If Google Play Protect warns about an unrecognised app, tap **Install anyway**. These test
   builds are not on the Play Store yet.
4. A newer build installs over the old one and keeps you signed in.

The restaurant and rider apps need an account from the Ziftee team.

These are test builds. Please report problems to the Ziftee team.
